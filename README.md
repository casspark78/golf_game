# ⛳ 골프 팀 점수 계산기

골프 경기에서 **2팀 이상**이 맞붙을 때, 각 팀 멤버들의 성적(이글/버디/파/보기)을 점수로 환산해 **팀별 총점과 승패**를 가려주는 아이폰용 앱입니다.

별도 설치(App Store) 없이 **아이폰 사파리에서 바로 실행**되고, 홈 화면에 추가하면 일반 앱처럼 전체화면으로 동작합니다.

---

## 주요 기능

- **모임(라운딩)별로 따로 저장** — 모임 제목으로 만들어 두면 목록에 남고, 나중에 다시 들어가 인원·점수를 입력/수정할 수 있습니다.
  - 저장은 브라우저(`localStorage`)에 되므로 앱을 닫았다 열어도 유지됩니다.
  - 모임 목록에는 팀/인원 수, 날짜, 현재 1위 팀이 함께 표시됩니다.
- **팀 수 / 팀당 인원 수**를 자유롭게 설정 (팀 2~12개, 인원 1~12명)
- 각 팀·멤버의 **이름**과 **이글 / 버디 / 파 / 보기 개수** 입력
- 점수 기준값을 변수로 직접 변경 가능 (모임을 만든 뒤에도 모임 안에서 변경 가능)
  - 기본값: 🦅 이글 **8점** · 🐦 버디 **5점** · 🟢 파 **2점** · 🔵 보기 **1점**
- **멤버별 점수 → 팀 총점 → 순위/우승팀**을 자동 계산 (무승부도 표시)
- 입력하는 즉시 멤버 점수와 팀 총점이 **실시간 반영**되고 자동 저장
- 팀별로 멤버를 추가/삭제할 수 있어 인원이 달라도 사용 가능

### 점수 계산 방식

```
멤버 점수 = (이글 개수 × 이글 점수)
          + (버디 개수 × 버디 점수)
          + (파 개수   × 파 점수)
          + (보기 개수 × 보기 점수)

팀 총점   = 팀에 속한 모든 멤버 점수의 합
우승팀    = 총점이 가장 높은 팀 (동점이면 무승부)
```

## 아이폰에서 사용하는 방법

이 앱은 정적 웹페이지(HTML 1개)라서 서버가 필요 없습니다. 아래 중 편한 방법을 쓰세요.

### 방법 A — GitHub Pages로 공개 (추천)

1. GitHub 저장소 **Settings → Pages** 이동
2. **Build and deployment → Source**를 `Deploy from a branch`로 설정
3. 브랜치를 이 앱이 있는 브랜치로 지정하고 `/ (root)` 선택 후 저장
4. 잠시 후 생성되는 주소(`https://<사용자>.github.io/golf_game/`)를 아이폰 사파리에서 열기

### 방법 B — 파일을 아이폰에서 직접 열기

`index.html`, `manifest.json`, `icon.svg`를 아이폰(파일 앱/아이클라우드 등)에 넣고 `index.html`을 사파리로 엽니다.

### 홈 화면에 앱처럼 추가하기

사파리에서 페이지를 연 뒤 **공유 버튼 → "홈 화면에 추가"**를 누르면, 아이콘이 생기고 전체화면 앱처럼 실행됩니다.

---

## 사용 순서

1. 첫 화면에서 **＋ 새 모임 만들기**를 누릅니다.
2. **모임 제목**, 팀 수, 팀당 인원 수, **각 팀 이름**(선택), 점수 기준을 정하고 **모임 만들기**를 누르면 모임이 저장되고 입력 화면으로 들어갑니다.
   - 팀 이름 칸은 팀 수에 맞춰 자동으로 늘어납니다(2팀이면 2칸). 비워두면 "팀 1", "팀 2"로 들어갑니다.
3. 각 멤버를 **한 줄**(이름 · 이글 · 버디 · 파 · 보기 · 점수)로 입력합니다. 팀 이름도 상세 화면에서 바로 수정할 수 있습니다. (입력 즉시 자동 저장)
   - 인원이 다른 팀은 **+ 인원 추가** 또는 멤버 옆 **×** 로 조정합니다.
   - 점수 기준을 바꾸려면 상단의 **⚙️ 점수 기준 / 팀 이름 수정**을 펼칩니다.
4. **결과 계산하기** 버튼을 누르면 순위와 우승팀이 표시됩니다.
5. 상단 **‹ 목록** 으로 나가면 모임이 저장된 상태로 목록에 남고, 다시 눌러 들어가면 이어서 입력할 수 있습니다.
   - 모임을 지우려면 목록에서 🗑 버튼을 누릅니다.

| 파일 | 설명 |
|------|------|

| `icon.svg` | 홈 화면 아이콘 |
